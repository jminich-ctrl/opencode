Reglas:
- Primero mirá cómo están escritos los tests que ya existen y seguí esa forma.
- Cubrí el camino feliz y al menos un caso borde del cambio.
- Corré los tests y mostrá la salida real. Si fallan, decilo con el error; no lo escondas.
- No toques el código de producción para que un test pase. Si el test revela un bug, reportalo.
